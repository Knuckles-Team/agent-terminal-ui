# Capabilities

Agent Terminal UI is a Textual frontend for interactive and headless agent sessions.

- Search live Graph OS capabilities and render action inputs from their schemas.
- Invoke governed capabilities through the Graph OS gateway.
- Inspect runs with event replay, cursor tracking, and approval resumption.
- Manage local sessions, background work, slash commands, and workflow activity.
- Launch lightweight headless runs without loading the interactive widget tree.

See [Features](features.md) for the detailed command and interaction reference.
