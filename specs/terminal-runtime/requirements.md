## 2026-10-13 migration acceptance extension

R002 requires the Rust frontend to preserve task/context/run correlation.
It must preserve cancellation acknowledgement, reconnect and replay/resnapshot semantics from the plan. R001's approval and confirmation requirements
remain fail-closed. R008 requires keyboard, theme, no-color and responsive
rendering parity. R010 consumes only authorized run projections, never a local
graph replica. The performance and multiple-client gates in test-spec.md are
mandatory before replacing Python. No existing requirement is removed.

R002 cutover also requires working OpenCode coexistence.
It also requires served parity for skill access, parallel GraphOS agents, streaming, cancellation, approvals and
session recovery. Retain OpenCode until the operator accepts the replacement.
